# Prediction of CO₂ Emission Intensity from Electricity Mix in France

## 📌 Objective

Predict the CO₂ emission intensity (gCO₂/kWh) of the French electricity
system using machine learning models and analyze the impact of different
energy sources.

## 📊 Dataset

-   lien:https:https://drive.google.com/drive/u/0/folders/1DZiIx8xgz_Qq2dXMu5fqaWOVCaEn_DQt
-   Source: RTE -- eCO2mix
-   Year: 2022
-   Frequency: 15 minutes
-   Variables: Electricity production by source, consumption, CO₂ rate

## 🧠 Models Used

-   Ridge Regression (main model)
-   Random Forest
-   XGBoost
-   SVR
-   Decision Tree
-   Lstm

## 📈 Evaluation Metrics

-   R²
-   RMSE
-   MAE
-   Overfitting analysis

## 🏆 Final Model

Ridge Regression (best trade-off between performance and
interpretability)
